# Bộ mockup biểu mẫu quản lý

Mở `index.html` bằng trình duyệt. Không cần backend, server, package manager hay Internet.

## Chụp màn hình
- Viewport đề xuất: 1440 × 900.
- Thu phóng: 90–100%.
- Mỗi biểu mẫu nên chụp 2–3 ảnh để chữ dễ đọc.
- Nút `Xuất / In` mở giao diện in của trình duyệt.

Toàn bộ dữ liệu là dữ liệu minh họa.
